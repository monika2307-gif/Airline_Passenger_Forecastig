# ✈️ Airline Passenger Forecasting using Time Series Analysis

## 📌 Project Overview
This project focuses on analyzing historical airline passenger data and forecasting future passenger demand using Time Series Analysis. It uses ARIMA and SARIMA models to identify trends, understand seasonal patterns, and predict passenger traffic for the next 24 months.

## 🎯 Objectives
- Analyze historical airline passenger trends.
- Perform Exploratory Data Analysis (EDA).
- Identify trend and seasonality in passenger data.
- Build ARIMA and SARIMA forecasting models.
- Forecast airline passenger demand for the next 24 months.
- Visualize actual vs. predicted passenger trends.

## 🤖 Models Used

**ARIMA (AutoRegressive Integrated Moving Average)**

Used to model time-dependent patterns and forecast future passenger values.

**SARIMA (Seasonal AutoRegressive Integrated Moving Average)**

Used to capture both trend and seasonal patterns in airline passenger data.

## 📈 Forecasting
The project generates passenger forecasts for the next 24 months using time series models and visualizes the predicted values alongside historical passenger trends.
